# 2-4 · 2-5 · 2-6 줄기 (2026-11-04. 첫 판 만듦: `docs/stage2.md` 「2-4 · 2-5 · 2-6 첫 판」)

2-3까지의 기록과 2-4~2-6을 만든 기록은 `docs/stage2.md`에 있다(2-3 작업 브랜치를 이 브랜치에 합침).

## 정한 것
- **2-4 = 병실(대화) → 라인(플레이) → 셧다운 → 트럭 출발.** **2-5 = 바다: 컷씬(고속도로, 어시장) → 해변에서 반장의 기타(플레이, 기타줄이 리듬게임) → 엔딩.** 스테이지 2는 2-5로 끝나지 않는다. 돌아온 뒤는 아직 정하지 않았다.
- **반장이 병실에서 마르코에게 기타를 준다.** 왜 주는지는 말하지 않고, 마르코도 모른 채 받는다. 바다에서 그 기타가 생각나 꺼내 치는 것이 2-5의 플레이.
- 반장이 쓰러진 이유는 **과로**. 큰 병이 아니다. 은퇴는 반장이 스스로 정한다.
- 마르코의 고향은 시카고가 **아니다**.
- 병실에서 리듬게임은 하지 않는다(기타 게임은 뺌). 병실은 대화만.
- 어시장에서 상자 나르는 플레이는 하지 않는다. 고속도로와 어시장은 컷씬.

## 무엇을 하는 밤인가 (2-4)
- 2-2부터 줄곧 "더 빨리"였던 마르코가 처음으로 **제 손으로 멈추는** 밤. 2-2에선 라인이 사고로 멈췄고, 2-4에선 마르코가 멈춘다.
- 마르코가 깨닫는 것: 그렇게 듣고 싶던 "에이스"가 반장을 병실에 눕힌 말이었다. **대사로 하지 않는다.** 소장이 마르코가 원하던 칭찬을 그대로 주는데 마르코가 웃지 않는 것, 마르코가 자기도 모르게 반장의 동작(허리 짚기)을 하는 것으로 보여 준다.
- 소장은 악역이 아니다. 소장의 "위에서"는 2-2 반장의 "…위에서나."와 같은 말이다.

## 2-4 흐름
1. **병실**(대화, 사용자 대본 `docs/stage2.md` 「2-4 인트로: 병실」): 반장이 깨어난다. 은퇴 얘기, 마르코의 고향. 마르코의 고향은 "바닷가 시장, 다들 노래하면서 일하는 곳"으로 깔아 둔다(2-5 바다의 밑자락).
   - "죽기 전에 거기나 한번 가야겠네." 다음엔 마르코가 받아 줘야 한다(과로로 쓰러진 직후라 큰 병으로 읽히지 않게). 마르코 "아, 그런 말 하지 마요!" / 반장 "…말이 그렇다는 거지."
   - 고향 대화 초안: 마르코 "(고향)요. 바닷가 시장 동네." / "거긴 다들 노래하면서 일해요. 생선 팔면서도." / 반장 "…시끄럽겠네." / 마르코 "엄청요."
   - **기타를 준다**: 반장 "어이, 신입. 거기 기타나 좀 줘봐."(사용자 대본) → 기타는 반장의 사물함에서 나온 것(20년 동안 꺼내지 않음, 줄이 녹슬었다). 반장은 치지 않는다. 한참 만지다가 몸통을 손바닥으로 한 번 툭(퇴근 전 벨트를 한 번 두드리던 습관) 치고 마르코에게 내민다.
     - 반장 "…마르코. 자네 가져." / 마르코 "네? 저 기타 못 치는데요." / 반장 "……" / 마르코 "…반장님?" / (반장은 눈을 감는다) / 마르코 "…일단 받을게요."
     - 이유는 2-5 끝에서 반장의 한 줄로만 비친다(아래).
2. **라인, 반장 없는 밤**(플레이): 소장이 내려와 마르코에게 라인을 맡긴다.
   - 소장 "마르코, 오늘부터 3라인은 자네가 봐." / "역시 에이스야." / "반장 빈자리만큼만 더 빼 줘." / 마르코 "…네."(웃지 않는다)
   - 마르코는 잘한다. 2-3에서 엉켰던 네 벨트 혼자 돌리기를 이번엔 해낸다. 실적표 숫자가 오른다.
   - 어느 순간 **마르코가 허리를 짚는다**(2-3에서 반장이 처음 무너지던 40박의 그 동작). 자기 손을 내려다보고, 카메라가 선반으로: 반장의 라디오, 그 옆에 2-3 오프닝에 두고 간 캔커피, 선반에 기대 세워 둔 **기타 케이스**(마르코가 어디 둘지 몰라 반장 자리에 가져다 둠).
3. **소장의 재촉**(멈춤 대사):
   - 소장 "좋아, 좋아. 이 속도면 내일부터 목표 올려도 되겠네."
   - 마르코 "…소장님. 반장님 병원 가 보셨어요?"
   - 소장 "위에서 보고 받았어. 일이나 해."
   - 마르코 "……" / "…다 꺼요, 그냥."
4. **셧다운**: 마르코가 메인 전원 레버로 가서 "신입. 같이 내려요." **마지막 노트 = 두 손 같이(레버)**, 2-1 "같이 오면 양손!"의 반복.
   - 내리는 순간 곡이 그 자리에서 끊김. 벨트 위 상자가 가다 말고 섬. 등이 바깥쪽부터 하나씩 꺼짐(2-2에서 반장이 나간 뒤 불이 꺼지던 것의 반대: 그땐 마르코가 남았고, 이번엔 마르코가 나간다).
   - 정적 속에서 마르코가 붐박스 대신 **반장의 라디오를 켠다**(블루스). 캔커피를 주머니에 넣고, **기타 케이스를 생각 없이 등에 멘다**(자기 짐 챙기듯. 화면에만 보이고 아무도 짚지 않는다).
   - 마르코 "신입, 바다 보러 갈래요?"(2-2 "신입, 소주 한잔할래요?"의 반복) / 소장 "마르코! 이거 다시 안 켜?!" / 마르코 "내일 할게요!"(2-2 반장의 "…내일 하자.")
5. **도크, 트럭 출발**: 04시 40분, 출차를 기다리던 트럭과 1-4·2-3의 기사.
   - 기사 "저기요! 물건 안 실어요?" / 마르코 "기사님, 이거 어디 가요?" / 기사 "…속초요." / 마르코 "타요, 신입!"
   - 매일 밤 상자를 보내기만 하던 둘이 상자 대신 실려 간다. 행선지는 송장이 정한 곳.

## 2-5 바다
### 컷씬 (플레이 없음, 1-7처럼 대사 적게)
1. **고속도로**: 반쯤 빈 짐칸, 기사의 트로트 라디오, 머리 위로 지나가는 터널 불빛. 마르코 등에 기타 케이스. 대사 거의 없음.
2. **새벽 어시장**: 상인들이 소리치고 흥얼거리며 얼음 상자를 나르고, 경매사가 노래하듯 값을 부르고 손짓으로 낙찰. 마르코 "…시끄럽네."(병실 반장의 "…시끄럽겠네."를 받음). 2-2 이후 처음으로 2-1의 마르코처럼 웃는다.
3. **해변, 동트기 전**: 모래에 앉아 식은 캔커피를 신입과 나눠 마신다. 등이 배겨서 케이스를 내려놓다가 **그제야 기타가 생각난다.** 마르코 "…아." 케이스를 연다.

### 플레이: 기타줄이 벨트가 된다
- **전환**: 녹슨 줄 클로즈업 → 카메라가 돌아(2-1의 축이 도는 연출처럼) 기타 넥이 화면을 가로로 가로지른다. 줄은 벨트, 프렛은 롤러, 사운드홀이 스캐너 자리. 2-4 끝에 멈춰 선 벨트가 기타줄로 다시 돈다.
- **노트**: 빛 알갱이가 줄을 타고 헤드 쪽(왼쪽)에서 사운드홀(오른쪽)로 흘러온다. 사운드홀 선에 닿을 때 친다. 맞히면 그 줄이 떨리며 소리가 나고, 놓치면 녹슨 줄 소리(지잉).
- **두 손**: 왼손(F/D, 화면 왼쪽) = **엄지, 아래 굵은 줄 셋**. 오른손(J/K/Space, 화면 오른쪽) = **손가락, 위 가는 줄 셋**. 엄지는 1·3박(반장의 정박), 손가락은 그 사이의 엇박(마르코의 리듬). 핑거스타일 기타 하나 안에 두 사람의 리듬이 같이 산다(2-2의 기싸움, 2-3의 합주에 대한 세 번째 답). 더 어렵게 하려면 줄 넷을 D F J K(2-1의 네 라인).
- **흐름(자리표)**:
  1. **혼자, 엉망**(짧게): 마르코가 아무렇게나 긁는다. 줄이 녹슬고 음이 안 맞아 소리가 엉망. 노트가 드문드문, 맞혀도 소리가 이상하다(맞힌 판정은 정상). 마르코 "…이거 왜 이래요."
  2. **전화**(멈춤 대사): 마르코가 반장에게 영상통화를 건다. 폰은 열린 케이스에 기대 세움. 화면 속 반장은 병실 침대.
     - 반장 "…라인은." / 마르코 "껐어요." / 반장 "……" / "…천천히 하랬지, 끄랬냐." / 마르코 "헤헤." / 마르코 "반장님, 이거 어떻게 쳐요?"
  3. **줄 감기**(튜토리얼): 반장 "줄부터 감아." 줄마다 한 번씩 튕겨 음을 맞춘다(한 줄에 노트 하나씩, 맞히면 녹슨 소리가 맑아짐). 화면 속 반장이 자기 손으로 시늉.
  4. **엄지**: 반장 "엄지는 가만 두지 말고, 아래만 왔다 갔다." 왼손만, 1·3박. 화면 속 반장의 손이 침대 난간을 같이 두드린다(동료 손을 보고 맞추는 규칙 그대로, 이번엔 폰 화면 속 손).
  5. **손가락**: 마르코가 위 줄에 자기 식의 엇박을 얹는다. 반장 "…그래. 그거."(2-3의 줄). 양손.
  6. **해돋이**: 해가 뜨면서 곡이 커진다. 파도가 박마다 밀려오고, 반장은 화면 속에서 난간을 두드리고, 신입은 캔을 두드린다. 반장 쪽 병실 창에도 같은 해가 든다.
- **곡**: 반장의 블루스(1-3의 시카고 블루스 계열)를 어쿠스틱 핑거스타일로, 뒤로 갈수록 마르코의 해변 그루브가 섞임. 파도 소리와 갈매기. 곡 프롬프트는 따로.

### 엔딩
- 마지막 화음이 울리고 파도 소리. 반장 "…바다는 어떠냐." / 마르코 "…시끄러워요. 좋아요." / 반장 "……" / 반장 "…거기선 다들 노래하면서 일한다며." / 마르코 "……"(기타를 내려다본다)
- 왜 기타를 줬는지는 이 한 줄로만 비친다. 병실에서 마르코가 말한 고향, 노래하면서 일하는 곳. 반장이 못 산 삶을 마르코는 살라는 것. 말로 풀지 않는다.

## 2-6 라인으로 돌아옴: 소장의 잔소리, 마르코의 되받아치기 (2026-11-04, 대본 초안)
사용자: 다시 라인으로 돌아온다. 소장이 뭐라 하지만 마르코는 무시하고, 소장 말 한마디 한마디를 되받아친다.
- **바닥**: 마르코의 붐박스와 반장의 라디오가 같이 켜져 있다(2-2에서 서로 끄던 둘). 선반에 반장의 기타 케이스. 반장은 아직 병원.
- **마르코의 성장**: 2-2 포장마차에서 마르코는 "이름 대신 '어이, 외국인'"이 서러웠다고 했다. 2-6에선 소장의 "외국인"을 웃으며 "한국인!"으로 되돌려 준다. 상처였던 말이 농담이 된다. 소장의 편견은 소장의 흠으로 보이게, 마르코의 억양은 웃음거리로 쓰지 않는다.
- **대본 초안**(소장이 한 줄 하면 마르코가 바로 받는다. 대사에 '박', '박자' 없음):
  1. 소장 "마르코! 어제 라인 누가 껐어!" / 마르코 "저요! 덕분에 바다 봤어요!"
  2. 소장 "바다? 지금 바다 얘기가 나와?" / 마르코 "네! 엄청 넓던데요?"
  3. 소장 "시말서 써 와!" / 마르코 "시는 못 쓰는데, 노래는 돼요!"
  4. 소장 "음악 꺼!" / 마르코 "끄면 손도 꺼져요~"
  5. 소장 "목표 수량은 어쩔 거야!" / 마르코 "즐겁게 일하죠!" / 소장 "일? 일이 즐거워?" / 소장 "이래서 외국인들은 안 돼…" / 마르코 "왜요? 한국인!"(사용자 대사)
  6. 소장 "…너 방금 뭐라 그랬어?" / 마르코 "소장님이 먼저 외국인이라 그랬잖아요~"
  7. 소장 "위에서 다 보고 있어!" / 마르코 (천장에 손을 흔든다) "안녕하세요~!"
  8. 소장 "반장 없다고 라인이 놀이터야?" / 마르코 "반장님이 천천히 하랬어요. 즐겁게는 제가 붙였어요."
  9. 소장 "실적 떨어지면 네 책임이야!" / 마르코 (실적표를 가리킨다) "딱 맞췄는데요? …이 정도면 돼요."(2-2 반장 "…이 정도면 된다.")
  10. 소장 "……" / 마르코 "소장님, 발 까딱거리시는데요?" / 소장 "…안 까딱거렸어."(2-3 절정에서 춤추던 소장)
- **플레이 아이디어(자리표)**: 1-5 랩 배틀처럼 **주고받기**. 소장 차례(한 마디) = 음악이 눌리고 소장이 클립보드를 탁탁 치는 뻣뻣한 정박 상자, 마르코 차례(한 마디) = 붐박스가 다시 올라오고 튀는 엇박 상자, 받아치는 대사의 끝말이 마디 첫 박의 양쪽 같이(짝 상자)에 꽂힘. 뒤로 갈수록 소장 차례가 짧아지고, 10에서 소장도 음악에 실려 버림.
- **엔딩: 마르코의 마지막 밤**(사용자). **스테이지 2에서 떠나는 사람은 마르코.** 2-6이 마르코의 마지막 근무였다는 걸 엔딩에서야 안다(그래서 소장한테 거침없었다).
  - (지문) 새벽 5시 50분. 라인이 멈췄다.
  - 마르코 "신입, 오늘 저 마지막이에요." / "10년 만에 고향으로 가거든요." / "오고 싶으면 얘기해요. 소주 한잔해요."(사용자 대사. 2-2 포장마차의 "신입, 소주 한잔할래요?"를 다시 부름)
