# 1-3 선곡 · 페이즈별 이펙트와 장면 전환 (작업 메모)

다른 세션에서 구현할 수 있도록 남기는 설계 메모. 코드는 `prototype/index.html`(`belt-beat`), 레벨 데이터는 `id:'s1-3'`.
음악 흐름: 지우 곡(피아노, 115) → 빌드 → 드롭 → 반장이 이어폰을 가져감 → 카운트 → 느린 블루스(60, 기타 리드) → 진입 → 합주(120, 드라이브 기타) → 브레이크(클린 기타) → 두 번째 드롭(신스 리드) → 아웃트로.

핵심: 음악의 주인이 바뀌는 걸 화면이 따라간다. **지우 = 연보라·하늘(`tintColors` [157,180,255] / [120,220,255]), 반장 = 호박색·파랑(라운지 스포트라이트)**, 합주 = 두 색이 한 화면에.

## 기존에 있는 재료
- `preClub`(박자마다 형광등에 색 틴트, `tintColors`), `dim`, `cut`(형광등 거의 끔, 조명 페이드 0.1배), `lounge`(호박/파랑 스포트라이트 + 연기, `drawLounge`), `club`/`hypePhases`(빔, 댄서, 미러볼, EQ 벽, 킥 쿵, 플래시: `drawClub`, `drawClubFront`, `hypeStage`, `clubFade`), 스캔 테마(`THEME.chill/blues`), 캐스트(`drawCast`: 반장이 걸어와 이어폰 듣기, 줄 그리기), `tapeStop`, 판정 팝업, 흔들림/줌 펀치(`FX.shakeUntil`, `FX.punchAt`), 파티클(`spawn`), 지우 포즈(`vibe`, `hype`, `unplug`).

## 장면별

| 구간(비트) | 이펙트 | 재료 |
|---|---|---|
| 인트로·절 (0~40) | 창고는 평소 형광등. 음악은 지우 귀에만 있으니 **지우 머리 주변에만 연보라 빛 방울**이 피아노에 맞춰 숨 쉬듯 커졌다 작아짐. 스캔 링 작고 연보라. 음표가 이어폰에서 조용히 떠오름 | 새로: 빛 방울(가산 합성 원, 반지름 피아노 히트에 맞춰) |
| 빌드 (40~72) | 빛 방울이 2마디마다 커져 벨트까지 번짐. 형광등이 킥마다 연보라로 물듦(`preClub`). 마지막 "숨 참기" 마디(68~72)는 `dim` 한 단계 | 거의 기존 |
| 드롭 (72~88) | 빛 방울이 터져 창고 전체가 연보라·하늘로(클럽 1단계를 연보라 팔레트로, 댄서·미러볼 없음). 레이저 색 바뀜. 지우 `hype` 점프. 반장이 걸어오는 동안(88~) 색이 **반장 쪽부터 빠져나감** | 클럽 재활용 + 색 마스크 |
| 자리 바꾸기 (88~96) | 반장이 이어폰을 귀에 대는 순간(89, `tinny`) 색이 전부 빠지고 형광등만. 음악이 작아진 만큼 **반장 귀 옆에 작은 빛 방울** 하나. 테이프 스톱(94.5)에 맞춰 형광등 깜빡이다 꺼짐. 한 박 암전 | 거의 기존 |
| 카운트 (96~100) | 어둠 속에서 림 한 번에 형광등 하나씩: 하나·둘·셋에 등 세 개, 넷에 '3' 표지판. 켜지는 색은 호박색 | 새로(작음): 튜브 alpha를 비트로 게이트 |
| 느린 블루스 (100~148) | 라운지 조명. 추가: '3' 표지판이 **네온사인처럼 깜빡임**, 기타 음마다 반장 쪽에서 벨트를 따라 호박색 잔물결, 그림자 길어짐. **지우 끄덕임이 4마디마다 커지고** 지우 주변 음표 색이 분홍 → 호박색(옛날 음악이 귀에 들어오는 중) | 조명 기존, 나머지 새로. 기타 음 타이밍은 `GLEAD`로 알 수 있음 |
| 진입 (148~152) | 스포트라이트가 두 배 킥에 맞춰 뜀. 스네어 롤 동안 벨트 가장자리 등이 16분으로 깜빡임. 라이저에 맞춰 화면 3% 당김 | 새로(작음) |
| 합주 (152~192) | 긴 미 벤딩(152) 순간 흰 플래시 + 흔들림, 스포트라이트가 스캐너로 휙 돎. 이후 **두 색이 한 화면에**: 기타 음 = 호박색 불꽃, 지우 킥 = 연보라 잔물결. 176(44마디)부터 벽 EQ 바(호박 + 연보라). 반장 발 까딱, 지우 통통 | 절반 기존 |
| 브레이크 (192~200) | 조명이 반장 스포트라이트 하나로 접히고 연기 짙어짐. 네 박 긴 화물을 누르는 동안 스캐너 빔이 그 화물을 따라 길게 비춤. 탐 필인 → 한 박 암전(199, `cut`) | 거의 기존 |
| 두 번째 드롭 (200~248) | 클럽 2→3단계를 **라운지 색으로**: 빔 5→7, 미러볼 대신 네온 표지판 스트로브, 바닥 연무, 킥마다 화면 쿵. 마지막 4마디(232~, 리드 옥타브 위) 마디마다 흰 스트로브, 모든 등 켜짐 | 기존 재활용(팔레트 파라미터화 필요) |
| 아웃트로 (248~) | 색이 전부 빠지고 평소 형광등. 둘만 남은 창고. 반장이 벨트를 한 번 두드림(1-4 모티프) | 작음 |

## 전환 아홉 번
1. 절 → 빌드: 빛 방울이 자람
2. 빌드 → 드롭: 숨 참기(어두움) → 터짐
3. 드롭 → 자리 바꾸기: 반장 쪽부터 색이 빠짐 → 이어폰 → 깜빡 → 암전
4. 카운트: 림마다 등 하나
5. 블루스 → 진입: 스포트라이트가 뛰기 시작
6. 진입 → 합주: 플래시와 흔들림
7. 합주 → 브레이크: 조명이 스포트라이트 하나로 접힘
8. 브레이크 → 두 번째 드롭: 암전 한 박 → 전부
9. 두 번째 드롭 → 아웃트로: 색이 빠짐

## 만드는 순서
- 1차(기존 조합): 전환 2·3·4·8·9, 두 번째 드롭 클럽 재활용(팔레트 파라미터), 브레이크 스포트라이트 하나.
- 2차(새 그림): 지우 빛 방울, 네온 표지판, 벨트 잔물결과 가장자리 등, 지우 음표 색 변화.
- 검증: `scratchpad`의 `check23.js`식 자동 플레이로 각 구간 스크린샷(비트 30, 60, 80, 92, 98, 120, 150, 153, 176, 195, 199.5, 220, 240).
