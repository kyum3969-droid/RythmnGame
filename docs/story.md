# 전체 줄기 (작업 중)

컨셉(`docs/concept.md`)의 "동료 한 명 = 챕터 하나"와 "동료들은 한 명씩 떠난다"를 따른다. 신입은 끝까지 대사가 없고, 스테이지마다 한 사람의 이야기를 옆에서 받아낸다.

## 정한 것 (2026-11-02)
- **로봇은 동료 캐릭터로 쓰지 않는다.** 플레이어에게 반감을 줄 수 있어서 뺐다. 컨셉 노트의 "분류 로봇", "마지막 페어는 로봇"은 폐기.
- **러브라인은 스테이지 1(지우·하은)에서 썼다.** 다음 스테이지에서 반복하지 않는다.
- **대사에 '박', '박자'를 쓰지 않는다.** 필요하면 '리듬', 대개는 규칙과 음악이 보여 준다.
- **이야기는 간접적으로.** 주제를 말로 하지 않는다.
