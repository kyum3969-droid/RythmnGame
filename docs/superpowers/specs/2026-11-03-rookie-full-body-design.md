# 신입 캐릭터 전신 적용

기준은 [승인된 원화](../../art/rookie-approved.png)의 얼굴 비율, 풍성한 머리, 접힌 후드,
굵고 느슨한 소매, 형광 조끼와 명찰이다. 이 형태를 유지한 전신 이미지에 작업 바지와 안전화를 연결한다.

- 원화에서 추출한 투명 PNG를 사용한다. 사각형으로 다시 그려 실루엣이나 비율을 바꾸지 않는다.
- 기본·스캔·놓침은 같은 크기와 발 기준점을 공유하는 세 프레임이다.
- 몸은 컨베이어 뒤에, 원화에서 분리한 팔·스캐너는 앞에 그린다.
- 중량물 손은 현재 포즈의 스캐너 그립에 맞추며, 두 벨트에서는 팔이 세 개 생기지 않게 한다.
- 패드·식사 장면은 스캐너를 제거한 몸과 원화의 소매를 사용한다.
- 게임의 논리 좌표는 384×216으로 유지한다. 메인 캔버스는 4배 해상도로 그려 원화 디테일을 보존한다.
- 조작·판정·레벨·오디오 데이터는 바꾸지 않는다.

## Approaches

공유 `prototype/rookie-art.js`가 `assets/rookie-sprites.png`를 불러와 몸·팔·도구를 분리한다.
동일한 원화 데이터를 게임과 참고 시안에서 사용해 모양이 달라지는 것을 방지한다.
현재 참고 시안은 `prototype/ref/rookie-rig.html`이다. 최신 main에서 제거된 이전 참고 시트와 애니매틱은 복원하지 않는다.

## Validation

원화와 실제 렌더링을 비교해 얼굴/머리 비율, 후드, 소매, 조끼와 신발의 형태를 확인한다.
기본·스캔·놓침·중량물·두 벨트·패드·반사 장면을 검사한다.
첫 레벨 완료와 실제 키 입력, 자산 로딩 성공/실패를 검증한다.
